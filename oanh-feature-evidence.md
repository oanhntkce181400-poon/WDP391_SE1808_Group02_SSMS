## Cach dung tren GitHub Web

1. Mo branch `codex/bangdcce181999-feature-evidence`.
2. Mo file nay.
3. Tim theo `ID` chuc nang.
4. Bam vao link `BE`, `FE`, `Commit`.
5. Khi dang mo file code:
   - bam `b` de mo `Blame`
   - bam `y` de doi sang permalink theo commit
   - bam `t` de tim file nhanh
   - bam `l` de nhay den line

## Ghi chu trang thai

- `Done`: da thay dau vet code chinh va commit Oanh lien quan.
- `Partial`: co code/commit lien quan nhung chua khop 100% mo ta backlog trong anh.
- `NotFound`: chua tim thay dau vet ro rang trong code hien tai.
